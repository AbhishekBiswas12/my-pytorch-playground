# my-pytorch-playground

A personal collection of PyTorch notebooks built while refreshing my knowledge of PyTorch and AI.

This repository is **not** intended to be a collection of PyTorch tutorials or API references. Instead, it serves as an experimental playground where I explore the concepts that underpin modern deep learning through implementation, experimentation, and careful observation.

Each notebook follows an implementation-first and research-oriented approach, focusing on understanding *why* things work rather than simply learning *how* to use an API.

## Goals

- Build strong intuition for PyTorch and tensor operations
- Understand the mathematical concepts behind deep learning implementations
- Learn through experiments instead of passive tutorials
- Develop research habits such as making predictions, testing hypotheses, and documenting observations
- Create a reusable reference library for future deep learning projects

## Repository Structure

The repository will gradually cover topics including:

- Tensor fundamentals
- Broadcasting and indexing
- Matrix operations
- Automatic differentiation (Autograd)
- GPU benchmarking and performance
- Reproducibility
- Training pipelines
- Neural network implementations
- CNNs, RNNs, Transformers
- Advanced PyTorch concepts encountered while reproducing research papers

## Learning Philosophy

The objective is not to memorize PyTorch APIs, but to build the intuition needed to implement, analyze, and improve deep learning models from first principles.
